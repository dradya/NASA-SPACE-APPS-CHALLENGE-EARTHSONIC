# public/media — NASA visualization frames

One folder per phenomenon, containing `frame-0001.webp` and so on, extracted from the SVS movies by `data-pipeline/`. Frames are resized for
screen use. Credit lines come from the SVS pages and are repeated in `ATTRIBUTION.md`. Design budget: about 30 MB in total.

`backgrounds/` contains optimized, user-supplied decorative images used behind the app and phenomenon cards. These are visual atmosphere only, not NASA imagery or scientific data.
