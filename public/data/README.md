# public/data — bundled, dated data snapshots

One folder per phenomenon (`sea-level`, `global-temperature`, `sea-ice`). Each holds:
- `manifest.json` (provenance, license, citation, alignment, snapshot date)
- `series.json` (numeric series; missing values are `null`, never filled)
- `frames.json` (frame index to date table and credit)
- `frame-features.json` (Track 2 only, precomputed)

Everything here is generated by `data-pipeline/`. Do not edit by hand and do not add demo or invented data.
